# AGENTS.md — Operational Manual: userscript-wb-ozon-comparator

## 1. Миссия, KPI и границы проекта (Mission & Scope)

- **Миссия:** Автономный Tampermonkey-юзерскрипт (`wb_ozon_comparator.user.js`) для глубокого кросс-маркетплейсного сравнения товаров на Wildberries и Ozon с учетом персональных цен (WB Кошелек, Ozon Карта), расчета удельной стоимости за 100 г / 1 шт, поддержки коллекций, автоматического скрытия сохраненных товаров в выдаче и экспорта в Excel (.xlsx).
- **Ключевые KPI:**
  - 100% точность расчета личной цены с учетом кошельков и скидок авторизованного пользователя.
  - Точное извлечение веса нетто/брутто и количества штук из характеристик карточек, imt_name и описаний.
  - Мгновенная фильтрация каталога и карточек товаров (подсветка/скрытие сохраненных артикулов).
  - Пакетная актуализация цен и остатков в 1 клик для всей коллекции лотов.
- **Границы и ограничения (Scope / Non-Goals):**
  - **In-Scope:** Аналитика Wildberries (`card.json`, `cards/v4/detail`, DOM-парсинг корзин) и Ozon (`entrypoints-v2`, `composer-api.bx`, SSR-дамп `__INITIAL_STATE__`), коллекции лотов в `GM_setValue`, экспорт в Excel через SheetJS.
  - **Non-Goals:** Автопокупка, ввод платежных данных, парсинг чужих аккаунтов.

## 3. Архитектурные правила и инварианты

1. **Единый самодостаточный юзерскрипт (`wb_ozon_comparator.user.js`):**
   Все зависимости (кроме `@require xlsx.full.min.js`) инкапсулированы внутри скрипта. Интерфейс рендерится через динамический DOM с CSS-модулями (`UIEngine`).
2. **Кросс-доменное хранилище коллекций (`StorageEngine`):**
   - Ключ `wb_ozon_comparator_collections_v2` хранит массив коллекций.
   - Ключ `wb_ozon_comparator_active_col_v2` хранит ID текущей выбранной коллекции.
   - Дедупликация лотов осуществляется строго по композитному ключу `${marketplace}_${sku}`.
3. **Движок Wildberries (`WBEngine`):**
   - Алгоритм CDN-корзин: `getBasketNumber(vol)` поддерживает корзины `basket-01` .. `basket-43+` (до `vol > 12000`).
   - Отказоустойчивый перебор корзин: при HTTP 404 перебираются кандидаты `[predicted, predicted±1, predicted±2, predicted±3]`.
   - Пакетное получение цен через API `https://card.wb.ru/cards/v4/detail?nm=...` (порциями до 100 артикулов).
4. **Движок Ozon (`OzonEngine`):**
   - Многоуровневое извлечение структуры: `entrypoints-v2` -> `composer-api.bx` -> дамп `__INITIAL_STATE__` -> DOM fallback.
   - Детекция цены по Ozon Карте через регулярные выражения и поиск ценников с зеленым бейджем.

## 4. Подводные камни и нетривиальные решения

1. **Динамическая адресация корзин WB:**
   Номер корзины не является строго монотонной функцией. Эвристический fallback-перебор соседних корзин гарантирует получение `card.json` в 99.9% случаев.
2. **Rehydration и SPA в Ozon:**
   Ozon использует микрофронтенды с асинхронной подгрузкой виджетов. Скрипт использует `MutationObserver` с дебаунсом (300 мс) и перехватчик `fetch` для стабильного извлечения данных без блокировки интерфейса.
3. **Изоляция стилей модального окна:**
   Стили диалоговых окон и таблиц используют специфичные классы `.wb-ozon-comp-*` с `!important` для защиты от агрессивного CSS маркетплейсов.
