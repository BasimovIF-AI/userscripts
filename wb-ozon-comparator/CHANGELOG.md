# Changelog

Все заметные изменения в проекте «WB & Ozon Comparator» документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [1.2.1] - 2026-09-21

### Fixed
- **Устранение ошибочного считывания баланса WB Кошелька из шапки вместо цены товара (`WBEngine.getDomPrice`):**
  - Устранена критическая ошибка, из-за которой глобальный поиск селектора `[class*="wallet-price"]` по `document` захватывал личный баланс WB Кошелька пользователя из шапки сайта (`navbar-pc`, например 31 ₽) вместо цены товара (782 ₽).
  - Поиск цен строго изолирован рамками блока покупки товара (`Buy Box` / `aside.product-buy` вокруг кнопки «В корзину» / «Купить сейчас»). Элементы шапки, меню, профиля пользователя и футера гарантированно исключены.
  - Позиционное отсечение: считываются только элементы цены, расположенные в DOM физически **выше кнопки покупки** (отсекая кредитные предложения «0 ₽» и альтернативные предложения продавцов «от 268 ₽», находящиеся ниже кнопок).
  - Фильтрация зачеркнутых цен (`del`, `s`, `line-through`) и кредитных фраз.
- **Прямое обновление цен Wildberries из API при массовом обновлении (`PriceUpdateEngine`):**
  - При нажатии «Обновить наличие и цены» для товаров Wildberries берется свежая актуальная цена из `cards/v4/detail` (`pInfo.productPrice`), а при открытой карточке товара — точная цена из блока покупки.
  - Ошибочные и застрявшие цены в базе гарантированно обновляются на реальные при массовой актуализации цен.

## [1.2.0] - 2026-09-21

### Added
- **Кнопка «Обновить наличие и цены» для текущей коллекции (`PriceUpdateEngine`):**
  - В модальном окне базы сравнения добавлена кнопка `🔄 Обновить наличие и цены`, работающая строго с товарами текущей активной коллекции.
  - Для Wildberries выполняется высокоскоростной пакетный опрос через `cards/v4/detail` (пачками по 80 артикулов).
  - Для Ozon выполняется асинхронный фоновый опрос страниц товаров через `fetchVariantDetails`.
  - Автоматически обновляются базовые и личные цены (с сохранением персональной скидки), пересчитываются удельные показатели «Цена за 100 г» и «Цена за 1 шт.».
  - Позиции, которых нет в наличии или снятые с продажи, маркируются контрастным бейджем «Нет в наличии», а строка таблицы визуально приглушается.
- **Полноценная система коллекций товаров (`StorageEngine` v2):**
  - **Выпадающий список коллекций** в шапке базы сравнения с отображением количества товаров в каждой коллекции.
  - **Кнопка `➕ Новая`**: создание новой пустой коллекции под произвольным именем.
  - **Кнопка `💾 Сохранить как...`**: сохранение текущего снимка товаров в новую именованную коллекцию (копирование подборки).
  - **Кнопка `✏️`**: переименование выбранной коллекции.
  - **Кнопка `🗑️`**: удаление коллекции с подтверждением (с защитой от случайного удаления последней).
  - **Интеграция с каталогом**: переключение активной коллекции мгновенно переключает фильтрацию в поиске/каталоге (`CatalogFilterEngine`), скрывая товары выбранной подборки.
  - **Экспорт в Excel по коллекциям**: имя выгружаемого файла и заголовок листа включают название активной коллекции.
  - **Бесшовная миграция**: ранее сохраненные товары автоматически перенесены в «Основную коллекцию» без потери данных.

## [1.1.1] - 2026-09-21

### Fixed
- **Надежное сохранение всех вариантов товара с одинаковой ценой в `StorageEngine`:**
  - Устранено ошибочное затирание артикулов при совпадении цены, веса и названия (`addItem` и `cleanDuplicates` ошибочно считали разные артикулы дубликатами и перезаписывали их).
  - Уникальность записи теперь строго определяется составным ключом маркетплейса и артикула (`${marketplace}_${sku}`). Каждый вариант товара гарантированно сохраняется в базе сравнения.
- **Гарантированное скрытие карточек серии и сестринских артикулов в каталоге/поиске (`CatalogFilterEngine`):**
  - При сохранении любого товара из группы автоматически запоминаются все связанные сестринские артикулы серии (`groupSkus` / `colors`) и идентификатор группы `imtId`.
  - При анализе карточек каталога извлекаются все связанные идентификаторы: `data-nm-id`, `data-card-id`, ID элемента (`c\d+`), ссылки `a[href*="/catalog/"]`, вложенные миниатюры цветов/вариантов и `data-imt-id`. Если хотя бы один идентификатор совпадает с сохраненными позициями или их сестринскими артикулами, карточка надежно скрывается.
  - Добавлена функция фонового обогащения ранее сохраненных записей списком сестринских артикулов группы (`StorageEngine.enrichStoredItemsWithGroups()`).
- **Кросс-вкладочная синхронизация состояния каталога:**
  - Добавлены обработчики событий `window 'focus'` и `document 'visibilitychange'` — при переключении на вкладку каталога/поиска после добавления товара в соседней вкладке фильтрация и скрытие применяются мгновенно без перезагрузки страницы.
  - Подключен слушатель изменений хранилища `GM_addValueChangeListener` для моментального обновления данных между всеми вкладками.

## [1.1.0] - 2026-09-21

### Added

  - Товары, которых нет в наличии (цена 0 ₽ / отсутствует у продавца), исключаются из активной выборки: чекбокс блокируется (`disabled`), строка визуально приглушается (`opacity: 0.55`), а в колонке цены отображается бейдж «Нет в наличии».
  - Кнопки «Выбрать все», «Снять выбор» и чекбокс в заголовке таблицы переключают только доступные для покупки товары.
- **Кнопка автопоиска и экспресс-добавления всех товаров в наличии:**
  - В плавающем доке (`#wbo-dock`) на страницах товаров Wildberries добавлена кнопка `⚡ Собрать все в наличии`: в один клик без необходимости открывать модалку находит все доступные варианты товара и сохраняет их в базу сравнения.
  - В футере модального окна анализа вариантов добавлена кнопка `⚡ Все в наличии в базу`, мгновенно сохраняющая все активные позиции из уже загруженного списка вариантов.
- **Интерактивные действия на карточках в поисковой выдаче и каталоге:**
  - Возле каждой карточки товара в каталоге и поиске Wildberries внедрен компактный блок действий:
    - Кнопка `➕ Сравнить`: экспресс-добавление конкретного товара из выдачи в базу сравнения в фоновом режиме (с определением характеристик, веса нетто, персональной цены).
    - Кнопка `📦 Всю группу`: автоматический поиск всей группы модификаций (`colors`), отбор позиций в наличии и пакетное сохранение всей серии в базу сравнения.
  - Карточка моментально скрывается из выдачи сразу после добавления, а плавающий счетчик скрытых позиций обновляется реактивно.

## [1.0.8] - 2026-09-20

### Fixed
- **Wildberries — Комплексное распознавание веса и модификаций при неполных характеристиках от продавца:**
  - `parseNetWeight`: добавлен интеллектуальный многоуровневый поиск веса нетто — при отсутствии поля «Вес товара без упаковки» в опциях выполняется сканирование названия товара (`imt_name`) и описания (`description`) по регулярным выражениям. Если вес нетто не указан нигде, автоматически используется вес с упаковкой (`weightGross`) как безопасный фолбек с флагом `isGrossWeight` (в таблице выводится `~X г*` с подсказкой «Рассчитано по весу с упаковкой»).
  - `parseItemsCount`: реализован парсинг количества предметов из названия лота (`160 шт`, `44 круг синий`, `14 шт`, `300 шт`) и артикула продавца `vendor_code` (`160`, `44кругсиний`, `14`), что устранило пустые прочерки в колонке «Кол-во».
  - `variantLabel`: устранена подстановка неинформативной заглушки `Артикул X`. Модификация теперь информативно объединяет вес, количество штук и отличительное название/вкус (например, `~820 г · 44 шт.`, `3500 г · 160 шт.`, `365 г · ТАЙСКИЙ МИКС`).
  - **Автоматический расчет метрик:** благодаря определению веса и количества штук для всех вариантов теперь корректно рассчитываются «Цена / 100г» и «Цена / 1 шт» вместо прочерков.

## [1.0.5] - 2026-09-20

### Fixed
- **Ozon — Переход на фоновый сбор вариантов через GM_xmlhttpRequest (устранение перезагрузки страницы):**
  - Диагностика выявила, что плитки невыбранных вариантов на Ozon являются ссылками `<a href="...">` с классом `pdp_f3`. Программный вызов `.click()` инициировал переход браузера по ссылке, прерывая работу скрипта до сохранения данных в хранилище.

    - Открытый в текущий момент вариант сохраняется мгновенно из активного DOM.
    - Все остальные выбранные варианты запрашиваются асинхронно в фоновом режиме по их прямым ссылкам `href` с сессией пользователя и скидкой Ozon Банка.
    - Внедрен нормализатор пробелов `\u2009` и `\u00a0` для цен Ozon Карты (например, `776 ₽`).
    - Страница пользователя больше не перезагружается и не мигает; модальное окно плавно отображает прогресс сбора.
