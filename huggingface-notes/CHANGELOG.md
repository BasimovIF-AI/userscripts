# Changelog

Все заметные изменения в этом проекте документируются в этом файле в соответствии со стандартом [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Проект придерживается семантического версионирования [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.1] - 2026-09-19

### Fixed
- **Исправлен рендеринг Markdown (одинарные тильды):** Подключен плагин через официальный механизм `marked.use({ tokenizer: { del } })`, обеспечивающий строгое соответствие спецификации GFM. Зачеркивание `<del>` теперь срабатывает исключительно по двойным тильдам (`~~зачеркнуто~~`), а одинарные тильды (`~1.58`, `~54 ГБ`) корректно сохраняются как математический знак приближения, не ломая полужирное выделение (`**~6 ГБ**`).
- **Стилизация списков и типографики:** Применен нативный класс Hugging Face `.prose dark:prose-invert max-w-none` (Tailwind Typography) к блоку предпросмотра. Это автоматически восстановило фирменные маркеры списков (`•`, `1.`), корректные межстрочные интервалы и полноценную поддержку темной/светлой темы HF без кастомных CSS-костылей.
- **Исправлен критический баг с удалением заметок:** Переработана логика футера модального окна:
  - В режиме **«Просмотр»** отображаются только кнопки `✏️ Редактировать` и `Закрыть` (кнопка сохранения скрыта, случайное удаление при клике на «Сохранить» полностью исключено).
  - В режиме **«Редактирование»** отображаются кнопки `Отмена` и `💾 Сохранить`.
  - Добавлено сохранение черновика при переключении между вкладками «Просмотр» и «Редактировать» без потери набранного текста.

## [1.0.0] - 2026-09-19

### Added
- Первоначальный релиз пользовательского скрипта Tampermonkey `Hugging Face Model Notes` (`hf_notes.user.js`).
- Интеграция бейджей-иконок на плашки моделей в каталоге `https://huggingface.co/models`:
  - Иконка `✏️` для моделей без заметок (открытие создания).
  - Выделенная иконка `📝` для моделей с сохраненными заметками (быстрый просмотр).
- Интеграция кнопки `📝 Заметка` в шапку страницы конкретной модели (`https://huggingface.co/<author>/<model>`).
- Всплывающее модальное окно с переключением между режимами:
  - **Просмотр:** рендеринг Markdown через библиотеку `marked.js` с поддержкой заголовков, списков, цитат, блоков кода и безопасных ссылок.
  - **Редактирование:** многострочный редактор с быстрой панелью форматирования (H1, H2, Bold, Italic, List, Code, Link).
- Горячая клавиша `Ctrl+Enter` / `Cmd+Enter` для мгновенного сохранения заметки.
- Закрытие модального окна по нажатию клавиши `Escape` или клику по оверлею.
- Модуль хранилища `StorageManager` на базе `GM_getValue`, `GM_setValue`, `GM_deleteValue`, `GM_listValues`.
- Функции резервного копирования в меню Tampermonkey:
  - `📥 Экспорт всех заметок (JSON)`
  - `📤 Импорт заметок (JSON)`
- Автоматическое отслеживание SPA-навигации Hugging Face (перехват `history.pushState`, `history.replaceState`, `popstate` и `MutationObserver` для динамической подгрузки карточек).
- Поддержка темной и светлой темы оформления сайта Hugging Face.
- Документация проекта: `README.md`, `CHANGELOG.md`, `PROJECT.md`.
