# AGENTS.md — Operational Manual: userscript-huggingface-notes

## 1. Миссия, KPI и границы проекта (Mission & Scope)

- **Миссия:** Автономный Tampermonkey-юзерскрипт (`hf_notes.user.js`) для платформы Hugging Face (`https://huggingface.co/*`), предоставляющий возможность создания, просмотра и редактирования локальных форматированных Markdown-заметок для моделей в каталоге (`/models`) и на персональных страницах моделей (`/<author>/<model>`).
- **Ключевые KPI:**
  - 100% точность идентификации modelId с отсечением системных служебных путей Hugging Face (`RESERVED_ROOT_PATHS`).
  - Мгновенный рендеринг GFM Markdown (через `marked.js`) с нативным стилем `.prose` (Tailwind Typography) и каноническими тильдами (`~1.58`).
  - Совместимость со светлой и тёмной темой сайта.
  - Персистентность базы заметок в хранилище `GM_setValue` с поддержкой экспорта/импорта в JSON.
- **Границы и ограничения (Scope / Non-Goals):**
  - **In-Scope:** Инъекция значков заметок в каталог моделей, кнопка в шапке страницы модели, модальное окно просмотра/редактирования, экспорт/импорт.
  - **Non-Goals:** Отправка заметок на сторонние серверы, редактирование системных описаний репозиториев (заметки приватны и хранятся локально).

## 3. Архитектурные правила и инварианты

1. **Единый самодостаточный юзерскрипт (`hf_notes.user.js`):**
   Зависит только от доверенного CDN `@require marked.min.js`. Стили инжектируются через `GM_addStyle`.
2. **Идентификация моделей и фильтрация маршрутов (`RouteMatcher`):**
   - Черный список `RESERVED_ROOT_PATHS`: `['models', 'datasets', 'spaces', 'docs', 'blog', 'pricing', 'login', 'join', ...]` предотвращает ошибочную инъекцию на системные страницы.
   - Канонический modelId извлекается как `${author}/${modelName}`.
3. **Слой хранения (`StorageManager`):**
   - Ключ хранения: `hf_note:${modelId}`.
   - Чтение: `GM_getValue`, сохранение: `GM_setValue`, удаление: `GM_deleteValue`.
   - Экспорт/импорт перебирает ключи через `GM_listValues()`.
4. **Рендеринг и изоляция модального окна (`ModalUI`):**
   - Контейнер `#hf-notes-modal-root` инжектируется в `document.body` с высоким z-index (`999999`).
   - Поддерживает горячие клавиши: `Ctrl + Enter` (сохранение), `Esc` (закрытие).

## 4. Подводные камни и нетривиальные решения

1. **SPA-навигация (Turbo / Next.js на Hugging Face):**
   При переходе по ссылкам страница не перезагружается. Скрипт использует `MutationObserver` с дебаунсом (250 мс) и отслеживает смену `window.location.pathname` для повторной разметки карточек моделей.
2. **Разметка одиночных тильд в marked.js:**
   По умолчанию marked может интерпретировать `~50` как незавершенное зачеркивание. Скрипт настраивает токенизатор для строгого GFM-правила (зачеркивание только через `~~...~~`).
3. **Безопасность пользовательских данных:**
   Все заметки хранятся исключительно в приватном хранилище браузера пользователя.
