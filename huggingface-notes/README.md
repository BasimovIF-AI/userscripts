# Hugging Face Model Notes (Tampermonkey Userscript)

**Версия:** `1.0.1`  
**Назначение:** Пользовательский скрипт для браузерного расширения Tampermonkey, позволяющий создавать, просматривать и редактировать структурированные текстовые заметки в формате Markdown (MD) для любой модели на платформе [Hugging Face](https://huggingface.co).

---

## Возможности

- **Интеграция в каталог моделей (`https://huggingface.co/models`):**
  - На каждой плашке модели отображается компактный индикатор:
    - `✏️` — заметка еще не создана. Клик сразу открывает редактор.
    - `📝` (выделенный) — для модели уже есть сохраненная заметка. Клик открывает быстрый просмотр.
- **Интеграция на страницу модели (`https://huggingface.co/<author>/<model>`):**
  - Кнопка `📝 Заметка` в шапке модели рядом с заголовком и системными кнопками.
- **Всплывающее окно (Modal Dialog):**
  - **Режим «Просмотр»:** полноценный рендеринг Markdown с помощью библиотеки `marked.js` и нативного класса Hugging Face `.prose` (Tailwind Typography). Поддерживаются канонические маркеры списков (`•`), заголовки, жирный/курсивный текст, цитаты, инлайн-код и блоки кода, кликабельные ссылки с открытием в новой вкладке.
  - **Строгий канон GFM:** одинарные тильды (`~1.58`, `~54 ГБ`) корректно отображаются как знак приближения и не вызывают ошибочного зачеркивания; зачеркивание работает строго через двойные тильды (`~~текст~~`).
  - **Режим «Редактирование»:** удобное поле ввода с панелью быстрой вставки Markdown-разметки (`# H1`, `## H2`, `**B**`, `*I*`, `- Список`, `</> Код`, `🔗 Ссылка`).
  - **Защита от случайного удаления:** в режиме просмотра доступны только кнопки `✏️ Редактировать` и `Закрыть`. Кнопка `💾 Сохранить` отображается строго в режиме редактирования.
  - Горячая клавиша **`Ctrl + Enter`** (или `Cmd + Enter`) для быстрого сохранения без отрыва от клавиатуры.
  - Закрытие по нажатию клавиши **`Esc`** или клику вне окна.
- **Резервное копирование и синхронизация:**
  - Меню Tampermonkey содержит пункты:
    - `📥 Экспорт всех заметок (JSON)` — выгрузка всех ваших заметок в файл для бэкапа.
    - `📤 Импорт заметок (JSON)` — загрузка заметок из резервной копии.
- **Адаптивный дизайн:**
  - Полная поддержка как светлой, так и темной темы Hugging Face.
- **Поддержка SPA-навигации:**
  - Корректная работа при переключении фильтров, сортировок, поиске моделей и переходе по страницам без перезагрузки вкладки.

## Требования к окружению

- Любой современный браузер: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, Brave, Opera.
- Установленное расширение для пользовательских скриптов:
  - [Tampermonkey](https://www.tampermonkey.net/) (рекомендуется)
  - или Violentmonkey.

## Пошаговая инструкция по установке

1. Откройте панель управления **Tampermonkey** в вашем браузере.
2. Перейдите на вкладку **«Утилиты»** или нажмите **«Создать новый скрипт»** (`+`).
3. Скопируйте целиком код из файла [`hf_notes.user.js`](./hf_notes.user.js).
4. Вставьте код в редактор Tampermonkey и сохраните: **Файл -> Сохранить** (или `Ctrl + S`).
5. Перейдите на страницу [Hugging Face Models](https://huggingface.co/models).
6. Теперь на каждой плашке модели будет доступна иконка заметок!

## Управление заметками

| Действие | Где находится | Описание |
| :--- | :--- | :--- |
| **Создать / Открыть заметку** | Плашка модели в каталоге или шапка модели | Клик по иконке `✏️` или `📝` |
| **Быстрое сохранение** | В окне редактирования | Нажмите `Ctrl + Enter` или кнопку `💾 Сохранить` |
| **Удаление заметки** | В окне заметки | Кнопка `🗑️ Удалить` с подтверждением |
| **Экспорт всех заметок** | Иконка Tampermonkey в браузере | Меню скрипта -> `📥 Экспорт всех заметок (JSON)` |
| **Импорт заметок** | Иконка Tampermonkey в браузере | Меню скрипта -> `📤 Импорт заметок (JSON)` |
