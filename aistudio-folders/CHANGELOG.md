# Changelog

Все заметные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования (SemVer)](https://semver.org/lang/ru/).

## [1.8.8] - 2026-10-05

### Added
- **Безотказная нативная инъекция данных синхронизации в protobuf-дерево (`findAndReplaceSyncPayload`):**
  - Разработаны рекурсивные методы `AISParser.findSyncPayload()` и `AISParser.findAndReplaceSyncPayload()`.
  - Полезная нагрузка синхронизации `AIS_SYNC_PAYLOAD::...` внедряется непосредственно в текстовое поле реплики без малейшего изменения protobuf-типов, массивов или служебных метаданных Google MakerSuite.
  - Устранена деструктивная перезапись `root[2] = [["user", [payloadString]]]`, вызывавшая фатальный сбой Google RPC `HTTP 400 (Unexpected list for single non-message field)`.

### Fixed
- **Идеальное выравнивание строки поиска с заголовком History:**
  - Контейнеру `.ais-search-wrapper` задано `position: relative`, а строка фильтров `.ais-scope-dots-row` переведена в абсолютное позиционирование `top: calc(100% + 3px); right: 0`.
  - Высота контейнера поиска теперь строго равна высоте инпута (36px), благодаря чему строка поиска выровнена строго по центру одной линии с заголовком `History`, сегментными кнопками (`All`, `My files`, `Shared`) и иконкой Google Диска.
  - В родительский тулбар добавлен `overflow: visible`, исключающий обрезку выпадающих фильтров.

### Changed
- **Миниатюрный размер шрифта фильтров «Область поиска»:**
  - Размер шрифта кнопок фильтров `.ais-scope-dot-btn` уменьшен с `10.5px` до `9px` (высота строки `12px`, зазор `gap: 3.5px`, паддинги `1px 2px`).
  - Текстовый лейбл «Искать в:» уменьшен до `8.5px`.
  - Микро-точки индикации уменьшены с `5px` до `4px`.
  - Блок фильтров гармонично и незаметно встроен под поле поиска, не перегружая шапку библиотеки.

## [1.8.7] - 2026-10-04

### Added
- **Надежное прямое автообнаружение диалогов по селектору `a.name-link, a[href*="/prompts/"]`:**
  - Сканирование ссылок на диалоги переведено на прямой селектор, гарантированно находящий все элементы библиотеки независимо от структуры строк таблицы (`mat-row`, `cdk-row`, `ms-library-table`).
  - Извлечение ID и названия диалога (`title` атрибут и текстовый контент) для немедленного наполнения `knownPrompts` и `IndexedDB`.
  - Защитный фоллбек: при пустом DOM список `knownPrompts` восстанавливается из существующих записей локальной базы данных.
  - Автоматическое превентивное сканирование диалогов в начале `pushToDrive()`, гарантирующее передачу актуальных данных на Google Диск.

### Fixed
- **Устранение ошибки Google Диска RPC `CreatePrompt: HTTP 400 (Unexpected list for single non-message field)`:**
  - Скорректирована структура чанков сообщений `root[2]` до точного формата `[["user", [payloadString]]]`, идентичного рабочему методу `UpdatePrompt`.
  - Устранено избыточное тройное/четверное вложение массивов при первичном создании системного файла `[AI Studio Enhancer Sync]`.
  - В перебор форматов конверта запроса `CreatePrompt` включены варианты `[root]`, `["", root]`, `[null, root]`, `[[root]]`.
- **Корректная обработка ошибок при ручной выгрузке (Manual Push):**
  - Метод `pushToDrive(onStatus, isManual)` теперь принимает флаг `isManual`. При ручном вызове ошибки не глушатся silently, а пробрасываются в UI с выводом точного текста ошибки в модальном окне и статусом `error`.
  - Устранено ложное всплывающее сообщение об успешном сохранении («Папок: 0, Диалогов в базе: 0») при фактическом сбое сетевого запроса.

### Changed
- **Редизайн статуса синхронизации в стиле Google Status Pill:**
  - Устранено раздельное вертикальное отображение точки и текста в карточке настроек.
  - Реализован авторский монохромный капсульный бейдж `.ais-sync-badge` с инкапсулированной микро-точкой 7px (`.ais-sync-badge-dot`), скруглением `9999px` и поддержкой темной/светлой темы.
  - Под капсулой аккуратно размещена метка времени последней синхронизации `.ais-sync-time-label`.

## [1.8.6] - 2026-10-04

### Added
- **Автообнаружение диалогов при синхронизации и открытии окна (Auto-Discovery):**
  - Добавлен метод `syncPromptsFromDom()`, мгновенно сканирующий таблицу библиотеки AI Studio и наполняющий локальную базу `IndexedDB` метаданными существующих диалогов.
  - В `fetchPromptList()` добавлено автосохранение всех возвращаемых Google MakerSuite диалогов в локальную базу и оперативную память `knownPrompts`.
  - В `pushToDrive()` внедрён защитный механизм предварительного обнаружения диалогов: если в локальной базе 0 записей, скрипт автоматически сканирует DOM и запрашивает актуальный список через API перед формированием пакета данных.

### Changed
- **Объединение статуса облачной синхронизации в карточке настроек:**
  - Из шапки модального окна полностью удалён дублирующий блок `.ais-header-sync`, освободив пространство и оставив чистую навигацию по вкладкам.
  - В карточке «Синхронизация через Google Диск» индикатор облака, статус («Все изменения сохранены в облаке») и время («Последняя синхронизация») объединены в единую интерактивную строку с живой анимацией пульсации при передаче данных.
- **Информативные уведомления облачной синхронизации:**
  - Устранено сбивающее с толку сообщение `Папок: 0, Диалогов: 0`. Уведомление теперь точно отображает общее число диалогов в базе и количество диалогов, распределённых по папкам.

## [1.8.4] - 2026-10-04

### Fixed
- **Предотвращение съезжания области поиска на вторую строку:**
  - Панели `.ais-lib-top-bar` задан строгий запрет переноса `flex-wrap: nowrap !important;`.

- **Полностью адаптивная тема окна настроек (устранение ложного тёмного режима):**
  - Удалён глобальный медиа-запрос `@media (prefers-color-scheme: dark)`, вызывавший принудительное включение тёмного оформления окна настроек в Windows с тёмной темой системы при светлой теме сайта.
  - Движок `detectAiStudioTheme()` теперь инспектирует реальный вычисленный цвет фона ключевых контейнеров страницы (`ms-library-page`, `main`, `.mat-drawer-content`), безошибочно определяя тему AI Studio.
  - Тема окна настроек синхронизируется при каждом открытии (`openModal()`), гарантируя стопроцентное совпадение со стилем интерфейса.

  - Теги папок отображаются только в корневом общем списке «Все диалоги» (`libSelectedFolderId === 'all'`).
  - При переходе в любую папку теги автоматически скрываются (`removeRowFolderBadge`), так как принадлежность диалогов к выбранной папке очевидна из контекста и хлебных крошек.

### Changed
- **Сверхкомпактная область поиска (Scope Strip) в масштабе шрифта сайта:**
  - Размер шрифта кнопок уменьшен до `11px`, высота капсулы снижена до `22px` (высота кнопок `18px`, паддинги `1px 7px`).
  - Элементы не превышают по высоте и размеру шрифт окружающего интерфейса и гармонично вписываются в тулбар библиотеки.

## [1.8.0] - 2026-10-04

### Added
- **Интеграция настроек расширения в родную шестерёнку Google AI Studio:**
  - Полностью удалена отдельная искусственная кнопка настроек из сайдбара.
  - Настройки AI Studio Enhancer (поиск, папки, облако Drive, переключатель разделов `BUILD`/`MANAGE`, ссылки на API-ключ и Model Tuning) теперь аккуратно внедряются прямо в нативное всплывающее меню кнопки `⚙️ Settings` (`mat-mdc-menu-panel`).
- **Контекстное меню по правому клику мыши (ПКМ) на папках:**
  - Убраны навязчивые кнопки действий при наведении курсора (`➕ ✏️ 🗑️`) и удалены всплывающие системные тултипы браузера, мешавшие обзору.
  - По правому клику мыши на папке открывается удобное контекстное меню: «Создать подпапку», «Переименовать (F2)», «Изменить цвет», «Удалить папку».
  - По правому клику на пустом месте списка: «Новая папка», «Обновить дерево», «Поиск диалогов».
- **Горячая клавиша F2:**
  - Быстрое переименование выбранной папки по нажатию клавиши `F2`.
- **Быстрая очистка поиска папок (кнопка ✕):**
  - В поле поиска папок добавлена инлайн-кнопка быстрой очистки `✕` и сброс фильтра по клавише `Escape`.
- **Минималистичный индикатор Google Drive:**
  - Удалена громоздкая плашка «Синхронизировано».
  - Рядом с поисковой строкой размещен аккуратный микро-виджет с официальной SVG-иконкой Google Диска и зеленым статусом-точкой `●` (с пульсирующим желтым режимом при синхронизации и красным при ошибке).

### Changed
- **Строгое позиционирование дерева папок под разделом «History»:**
  - Исправлена ошибка поиска элемента в навигации, когда пункт «Playground» с ссылкой `/prompts/new_chat` перехватывал размещение дерева папок. Папки теперь всегда строго расположены под «History».
- **Лаконичный вид списка папок без лишних иконок:**
  - Папки пользователя теперь отображаются минималистично — без повторяющейся желтой иконки `📁`. Иконки сохранены только для системных разделов «Все диалоги» (`📁`) и «Без папки» (`📂`).
- **Резиновая адаптивная высота раздела папок:**
  - Заменена фиксированная высота на динамическую адаптивную высоту (`calc(100vh - 260px)` с автоматическим вычислением расстояния до нижнего блока профиля/аккаунта и реакцией на `resize`).

  - Отображение точной информации: «Проиндексировано: 962 из 962 (960 с сообщениями, 2 пустых/системных)».
