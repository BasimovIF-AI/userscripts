# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.2.0] - 2026-09-21

### Changed
- **In-Place замена ссылок SubID (Zero-DOM Overhead):**
  - Полный отказ от создания и вставки в DOM отдельных кнопочных элементов `[🚀 В Steam]`.
  - Скрипт напрямую преобразует существующие ссылки на SubID (`<a href="/sub/1747068/" class="package">1747068</a>`), заменяя их адрес на URL прямого автоперехода в Steam: `/sub/<id>/#autosteam?subid=<id>`.
  - Ссылки автоматически открываются в новой вкладке (`target="_blank"`).
- **Ультралегкий CSS-визуал:**
  - К ссылкам добавлен ненавязчивый индикатор ракеты через CSS псевдоэлемент `::after { content: ' 🚀'; }`, который отрисовывается браузером без создания узлов в DOM и без срабатывания `MutationObserver`.
  - Добавлен информативный тултип при наведении: `🚀 Открыть пакет <id> в магазине Steam (прямой переход по AppID)`.

## [3.1.0] - 2026-09-21

### Added
- **Внедрение кнопок [🚀 В Steam] в лог активации `#loading` (Post-Activation Mode):**
  - Кнопки генерируются строго **после** нажатия «Activate packages» расширения SteamDB в реальном времени внутри панели лога `#loading` рядом с каждой строкой пакета (например, `Package 1747068 [🚀 В Steam] - [Ignore] Steam says this is an invalid package.`).
  - До запуска активации страница остается абсолютно чистой — исключены любые модификации таблицы `#freepackages`.
- **Прямой fallback на страницы пакетов Steam (`store.steampowered.com/sub/<subId>/`):**
  - При ошибках SteamDB (HTTP 451 `Error · SteamDB`, геоблокировка, 404) или отсутствии AppID в DOM скрипт автоматически перенаправляет напрямую на страницу пакета в магазине Steam.

## [3.0.2] - 2026-09-21

### Fixed
- **Устранение циклического дублирования кнопок (Защита от самоселекции):**
  - Устранена ошибка бесконечного размножения кнопок `[🚀 В Steam]` в строках пакетов, вызванная тем, что создаваемая кнопка `<a href="/sub/.../#autosteam">` подпадала под селектор `container.querySelectorAll('a[href*="/sub/"]')` и при срабатывании `MutationObserver` рекурсивно вызывала создание новой кнопки.
  - Селектор поиска обновлен на `a[href*="/sub/"]:not(.tm-steam-autoclick-btn)`.
  - Добавлены многоуровневые защитные проверки: `link.classList.contains('tm-steam-autoclick-btn')`, `sibling guard` (`link.nextElementSibling.classList.contains('tm-steam-autoclick-btn')`) и маркировка `btn.dataset.tmAutoSteam = 'true'`.

## [3.0.1] - 2026-09-20

### Fixed
- **Точечная генерация кнопок (Оптимизация производительности DOM):**
  - Устранено зависание страницы `https://steamdb.info/freepackages/`, вызванное поиском ссылок по всему `document` (включая скрытые контейнеры `#freepackages_all`, `#freepackages_ignored` и `#freepackages_owned` с более чем 35 850 элементами).

- **Дебаунсинг MutationObserver:**
  - Добавлена задержка 150 мс перед вызовом `injectSmartButtons()`, предотвращающая многократные повторные вызовы при пакетных обновлениях DOM расширением SteamDB.

## [3.0.0] - 2026-09-20

### Changed
- **Радикальное упрощение архитектуры (KISS / On-Click Autoredirect):**
  - Полный отказ от фонового сетевого опроса `fetch()`, очередей, рандомизированных задержек 1–10 секунд и базы данных IndexedDB.
  - Скрипт сокращен с ~1600 строк до ~150 строк максимально быстрого и чистого кода без сторонних абстракций.
  - Логика переведена на событие клика пользователя: рядом с каждым пакетом на `freepackages/` размещена кнопка `[🚀 В Steam]`.

### Added
- **Двухэтапный умный переход:**
  - На `https://steamdb.info/freepackages/*` формируется ссылка `/sub/<id>/#autosteam` с передачей очищенного названия игры.
  - На `https://steamdb.info/sub/*` скрипт автоматически извлекает все AppID пакета из DOM открытой страницы и мгновенно перенаправляет пользователя на страницу игры в магазине Steam (`https://store.steampowered.com/app/<AppID>/`).
- **Поддержка мульти-пакетов:**
  - Если в пакете несколько игр — открывает все игры во вкладках, а текущую переводит на первую игру.
- **Умный fallback при ошибках SteamDB (HTTP 451 / геоблок / 404):**
  - Если страница пакета заблокирована SteamDB для региона пользователя (`Error · SteamDB`), скрипт автоматически перенаправляет на поиск игры в Steam по переданному очищенному названию.
- **Поддержка динамического контента:**
  - `MutationObserver` автоматически добавляет кнопки при асинхронной подгрузке пакетов расширением SteamDB.

### Removed
- Локальная база данных IndexedDB (`SteamDB_LocalDB`).
- Компонент `ProgressBarUI` и модальное окно глубокой диагностики.
- Фоновый опрос каталога и дебаунс-таймеры.

## [2.3.3] - 2026-09-20

### Added
- **Модуль глубокой диагностики (Deep Diagnostic Suite):**
  - Интерактивная кнопка **«🔍 Диагностика»** на панели управления `ProgressBarUI`.
  - Всплывающее модальное окно с детальным отчетом диагностики без необходимости открывать инструменты разработчика.
  - **Live Probe (Сетевой зонд):** отправка тестового запроса к целевому SubID с фиксацией HTTP-статуса, времени ответа, размера HTML, заголовка страницы `<title>` и заголовков ответа (`server`, `cf-ray`, `content-type`).
  - **Автодетектирование защиты Cloudflare:** обнаружение WAF/Turnstile/Challenge (HTTP 403, "Just a moment...", `cf-challenge`) с понятным разъяснением причины блокировки `fetch()` на стороне Cloudflare.
  - **Пошаговая телеметрия 4 уровней парсера:** детализированный отчет о результатах поиска на каждом из 4 уровней (`tr[data-appid]`, секция *«Apps in this package»*, контентные ссылки `/app/`, Regex по сырому HTML).
  - **Диагностика хранилища IndexedDB:** проверка статуса подключения, подсчет записей, проверка наличия кэша для конкретного SubID.
  - **Кнопка «📋 Скопировать отчет»:** форматирование полного диагностического отчета в Markdown и копирование в буфер обмена в один клик.
  - **Кнопка «🧹 Очистить кэш IndexedDB»:** сброс сохраненных данных в `sub_packages` и оперативной памяти для устранения устаревших данных.
- **Новые методы `AppDB`:**
  - `AppDB.clear(): Promise<boolean>` — полная очистка локального хранилища `sub_packages` и памяти `memoryCache`.
  - `AppDB.count(): Promise<number>` — точный подсчет сохраненных записей в IndexedDB.

## [2.3.2] - 2026-09-20

### Fixed
- **Канонический URL опроса пакетов `/sub/<id>/`:**
  - Устранен запрос к несуществующему подпути `/sub/<id>/apps/`, вызывавший прерывание запросов с ошибкой.
  - Опрос пакета теперь всегда идет напрямую к действительному адресу `https://steamdb.info/sub/<subId>/`.
- **4-уровневый отказоустойчивый парсер `parseAppsFromSubHtml`:**
  - Уровень 1: Поиск строк `tr[data-appid]`.
  - Уровень 2: Поиск секции *«Apps in this package»* (по заголовку) и следующей за ним таблицы с извлечением ссылок `<a href="/app/<id>/">`.
  - Уровень 3: Поиск всех ссылок `a[href*="/app/"]` в основном контенте страницы с исключением служебных блоков (`nav`, `header`, `footer`, `.navbar`).
  - Уровень 4: Поиск регулярным выражением `/\/app\/(\d+)\/?/g` по сырому HTML (на случай JS-структур или нестандартной разметки).
- **Диагностическое логирование:**
  - В консоль браузера выводятся подробные сведения об HTTP-статусах и возможных сбоях обработки.

## [2.3.1] - 2026-09-20

### Fixed
- **Исправление URL опроса приложений пакета в `fetchSubApps`:**
  - Запрос направляется на вкладку приложений `/sub/${subId}/apps/` (где расположена таблица `tr[data-appid]`), а не на базовую страницу `/sub/${subId}/` (которая содержит только вкладку Information без списка игр).
  - Добавлен автоматический fallback на базовую страницу `/sub/${subId}/` при коде 404 или отсутствии приложений.
- **Полное исключение ссылок на SubID (`store.steampowered.com/sub/`):**
  - Устранена проблема, из-за которой при ошибках или задержках создавалась ссылка на SubID вместо AppID.
  - Все ссылки формируются **строго** на `https://store.steampowered.com/app/<AppID>/`.
  - При отсутствии AppID теперь выводится информационный бейдж `[⚠️ AppID не найден]` без создания ссылки на SubID.

## [2.3.0] - 2026-09-20

### Added
- **Прямой переход на страницы приложений Steam по AppID (Direct AppID Links):**
  - Все ссылки на игры теперь формируются строго по схеме: `https://store.steampowered.com/app/<AppID>/`.
  - Поиск в Steam (`store.steampowered.com/search/?term=...`) полностью исключен из скрипта.
  - Полноценная поддержка составных пакетов (Multi-App SubID): если в SubID входит несколько приложений (игры, DLC, саундтреки), для **каждого** приложения создается отдельная прямая ссылка по его AppID.
  - Мульти-пакеты подсвечиваются ярким тегом `[🔥 Пакет: N приложений]` с всплывающим списком всех включенных игр.
  - В случае, когда AppID пакета не удалось извлечь, формируется прямой переход на страницу пакета `https://store.steampowered.com/sub/<SubID>/` (который в Steam автоматически открывает страницу игры).

### Fixed
- **Исправление запроса к SteamDB в `fetchSubApps`:**
  - Переход на канонический URL `/sub/${subId}/` (где в HTML расположена таблица `tr[data-appid]`).
  - Удален заголовок `'X-Requested-With': 'XMLHttpRequest'`, вызывавший блокировку Cloudflare.
- **Очистка и защита базы данных IndexedDB:**
  - `AppDB.get` теперь игнорирует пустые ошибочные кэши (`apps: []`), позволяя автоматически переопределить настоящие AppID для ранее сохраненных с ошибкой пакетов.
  - `AppDB.set` больше не кэширует пустые массивы при сетевых сбоях.

## [2.2.0] - 2026-09-20

### Added
- **Опрос исключительно видимых пакетов (Visible Only Mode):**
  - Реализована функция глубокой проверки видимости `isElementVisible()` с использованием `checkVisibility()`, `offsetParent !== null`, `getComputedStyle()` и `getBoundingClientRect()`.
  - Устранена проблема опроса 35 000+ скрытых пакетов в каталоге SteamDB: теперь обрабатываются только отображаемые пользователю пакеты (например, 4 пакета вместо 35 854).
  - Динамическая отмена опроса в очереди: если пользователь нажимает `[Ignore]` или пакет скрывается, запрос для него отменяется без траты времени ожидания.
  - Безопасный наблюдатель `MutationObserver` с дебаунсом 300 мс для обнаружения динамически появившихся видимых пакетов (при задержке загрузки расширения SteamDB).
- **Динамическая адаптация прогресс-бара:**
  - Методы `updateTotal()` и `decrementTotal()` для автоматической корректировки счетчика `(X / N)` при добавлении или скрытии пакетов.

## [2.1.0] - 2026-09-20

### Added
- **Единая полоса прогресса (Progress Bar):**
  - Визуальная полоса прогресса над списком бесплатных пакетов с динамическим процентом выполнения и индикатором заполнения.
  - Детализированный счетчик: `(X / N)`, статус выполнения, количество обнаруженных игр и обратный отсчет задержки до следующего пакета.
  - Интерактивное управление очередью: кнопки `[⏸️ Пауза / ▶️ Продолжить]` и `[⏹️ Стоп]`.
  - Автоматическая смена стиля полосы на изумрудно-зеленый цвет при 100% завершении обработки.
- **Строгий контроль жизненного цикла вкладки (Strict Tab Lifecycle):**
  - Полное исключение фоновой работы при закрытии вкладки: обработчики событий `beforeunload` и `pagehide`.
  - Использование `AbortController` для моментального прерывания активного сетевого запроса `fetch`.
  - Очистка очереди запросов и сброс активных таймеров `clearTimeout` при уходе со страницы или нажатии кнопки «Стоп».

## [2.0.0] - 2026-09-20

### Added
- **Глубокий переход в SubID:** Скрипт запрашивает страницу пакета `/sub/<SubID>/apps/` и извлекает точные `AppID` игр для формирования прямых ссылок `https://store.steampowered.com/app/<AppID>/`.
- **Рандомизированная задержка 1–10 секунд:** Каждый сетевой запрос выполняется с человекоподобной случайной паузой от 1000 до 10000 мс, что полностью предотвращает rate-limit и защиту Cloudflare.
- **Локальная база данных IndexedDB (`SteamDB_LocalDB`):**
  - Структурированное сохранение записей: `{ subId, dateTime, apps: [{ appId, name }] }`.
  - Ранее запрошенные пакеты отображаются моментально (0 мс) без повторного обращения к сети.
- **Визуальное выделение составных пакетов (>1 игры):**
  - Пакеты с несколькими играми подсвечиваются ярким золотистым бейджем `[🔥 Пакет: N игр]` с акцентным стилем.
  - Рядом выводятся отдельные ссылки на каждую игру пакета.
- **Автоматический запуск при загрузке:**
  - Благодаря режиму `@grant none` скрипт больше не мешает расширению SteamDB и запускается сразу при открытии страницы.
