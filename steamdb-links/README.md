# SteamDB Free Packages - Direct Steam Game Links

Ультралегкий пользовательский скрипт для расширения **Tampermonkey** / **Violentmonkey**, который обеспечивает мгновенный умный переход из SubID пакетов на странице `https://steamdb.info/freepackages/` непосредственно на страницы игр в магазине Steam (`https://store.steampowered.com/app/<AppID>/`).

> [!TIP]
> **Версия 3.2.0 (In-Place Link Transformation & Zero-DOM Overhead):** Прямая трансформация существующих ссылок на SubID (например, `Package 1747068 🚀`). Полный отказ от создания дополнительных кнопочных элементов в DOM. Нулевая нагрузка на процессор, отсутствие циклов `MutationObserver`, аккуратный CSS-визуал `::after` и подсказка при наведении. При клике по номеру пакета в логе `#loading` открывается страница пакета с мгновенным автопереходом на страницу игры в магазине Steam (`store.steampowered.com/app/<AppID>/`).

---

## 🎯 Возможности

- 🚀 **In-Place умный переход по клику на номер пакета:**
  - Никаких лишних кнопок: существующая ссылка `<a href="/sub/<id>/" class="package">1747068</a>` напрямую преобразуется в умную ссылку прямого перехода в Steam.
  - Ссылка открывается в новой вкладке (`target="_blank"`).
  - Скрипт на открывшейся странице моментально считывает AppID и перенаправляет на `https://store.steampowered.com/app/<AppID>/`.
- ⚡ **Нулевые накладные расходы на DOM (Zero-DOM Overhead):**
  - Не создается ни одного нового узла DOM.
  - Дерево элементов не перестраивается, полностью исключая рефлоу и каскадные срабатывания `MutationObserver`.
- 🎨 **Ультралегкий визуал через чистый CSS:**
  - Ненавязчивый индикатор ракеты `1747068 🚀` через CSS псевдоэлемент `::after`.
  - Информативный тултип при наведении курсора: `🚀 Открыть пакет <id> в магазине Steam (прямой переход по AppID)`.
- 🛡️ **Прямой fallback в магазин Steam (`store.steampowered.com/sub/<subId>/`):**
  - Если страница пакета на SteamDB заблокирована для вашего региона (HTTP 451 `Error · SteamDB`) или таблица приложений недоступна, скрипт автоматически перенаправляет напрямую на страницу пакета в Steam.
- 🔥 **Поддержка составных пакетов (Multi-App):**
  - Если в SubID входит несколько приложений (игры/DLC) — скрипт открывает все игры во вкладках, а текущую переводит на первую игру.

## 📋 Требования к окружению

- **Браузер:** Google Chrome, Yandex Browser, Mozilla Firefox, Microsoft Edge, Opera или любой совместимый Chromium-браузер.
- **Менеджер пользовательских скриптов:**
  - [Tampermonkey](https://www.tampermonkey.net/) (рекомендуется)
  - [Violentmonkey](https://violentmonkey.github.io/)
- **Расширение SteamDB:** Официальное расширение [SteamDB Browser Extension](https://steamdb.info/extension/).

## 🚀 Установка

1. Откройте расширение **Tampermonkey** в браузере.
2. Создайте новый скрипт (кнопка `+`).
3. Скопируйте и вставьте содержимое файла [`steamdb_link_game.user.js`](./steamdb_link_game.user.js).
4. Нажмите `Ctrl + S` (или **Файл -> Сохранить**).
5. Перейдите на страницу [SteamDB Free Packages](https://steamdb.info/freepackages/) и нажмите зеленую кнопку **«Activate packages»** — в появляющемся логе кликайте прямо по номерам пакетов `1747068 🚀` для перехода в Steam.

## ⚙️ Настройки и параметры

| Параметр | Значение | Описание |
|---|---|---|
| Метод трансформации | `In-Place URL Rewrite` | Подмена адреса существующей ссылки SubID |
| Нагрузка на DOM | `0 новых элементов` | Модификация `href` без создания кнопок |
| Визуальный индикатор | `CSS ::after (' 🚀')` | Отрисовка графическим движком браузера без узлов DOM |
| Мульти-пакеты | `Поддерживаются` | Автоматическое открытие всех AppID из состава SubID |
| Обработка 451 | `store.steampowered.com/sub/` | Прямой редирект на пакет в Steam при ошибках SteamDB |
| Фоновые процессы | `Отсутствуют` | Скрипт не выполняет сетевых запросов в фоне |
| `SCRIPT_VERSION` | `3.2.0` | Текущая версия скрипта |
