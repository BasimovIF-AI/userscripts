## 📖 Описание проекта

Скрипт решает главную проблему пользователей Steam с большими библиотеками (от десятков до сотен тысяч лицензий): **отсутствие встроенного поиска и невозможность прямой навигации** по страницам списка лицензий аккаунта.

Поскольку Steam формирует пагинацию с использованием закрытых курсоров `continuationToken` (например, `continuationToken=1788701525:89663039558846018&offset=100`), перейти вручную на произвольную страницу (например, 350 из 700) невозможно без последовательного перехода по кнопке «Дальше >».

### Основные возможности:
1. **Неразрушающий сбор данных (Non-destructive):**
   - Никакие операции запуска сбора **не стирают базу данных**. Все уже собранные лицензии сохраняются и обновляются.
   - Очистка базы возможна исключительно по явному нажатию красной кнопки «🗑 Очистить всю базу данных» на вкладке «База и Экспорт».
2. **Единая умная синхронизация без лишних проходов (Smart Sync):**
   - Единая кнопка **«▶ Синхронизировать базу»** объединяет первоначальную выгрузку и повседневное обновление.
   - **Если база пуста:** скрипт последовательно обходит все страницы (1–703), заполняя каталог с нуля.
   - **Если база уже заполнена:** скрипт начинает со стр. 1 (самые свежие лицензии) и **моментально останавливается** (< 0.1 сек.), как только встречает первую игру, уже имеющуюся в базе.
   - Никаких холостых проходов по сотням уже скачанных страниц!
3. **100% сохранение всех лицензий (1-в-1 с каталогом Steam):**
   - Все дубликаты записей (несколько ключей одной игры, повторные покупки, внутриигровые кейсы/предметы на одну дату) сохраняются под уникальными ключами со сквозным счетчиком (`:::dup1`, `:::dup2`), исключая схлопывание записей.
   - Строки с пустым названием (старые удаленные товары) корректно сохраняются без отбрасывания.
4. **Нативная форма перехода по страницам в стиле Steam:**
   - В стандартные блоки пагинации Steam (`.license_paginator_ctn`), над и под таблицей лицензий, гармонично встроена панель перехода:
     - Кнопки: `[⏮ 1]`, `[◀]`, `[▶]`, `[703 ⏭]`.
     - Форма ввода номера страницы: `Стр. [ N ] из 703` с кнопкой `[➔]` и поддержкой перехода по нажатию клавиши `Enter`.
     - Стилизовано под нативный темный интерфейс Steam (Motiva Sans, синяя подсветка, градиент).
5. **Компактный поиск и переход к игре в 1 клик:**
   - Мгновенный поиск по 70 000+ лицензиям в реальном времени.
   - Ультракомпактный табличный вид без визуального мусора: только дата, название игры и бейдж типа приобретения.
   - Вся строка игры интерактивна: клик в любое место сразу открывает точную страницу Steam и подсвечивает нужную строку.
6. **Возобновление прерванного сбора:**
   - Кнопка **«🔄 Возобновить»** активна, только если процесс сбора был остановлен на середине (пауза, обрыв сети). Если вся библиотека выгружена — кнопка автоматически блокируется.
7. **Детерминированные уникальные ключи записей:**
   - Каждая лицензия идентифицируется по связке `(название + packageId + дата + способ покупки)`.
   - При добавлении новых игр дубликаты не создаются, а существующие записи обновляются.
8. **Локальная база данных IndexedDB (`SteamLicensesDB`):**
   - Рассчитана на библиотеки в 70 000+ лицензий. Быстрые индексы по названию, PackageID, способу получения, номеру страницы и токену.
9. **Экспорт и резервное копирование:**
   - Экспорт всей базы в `JSON` и `CSV` (UTF-8 BOM).
   - Импорт из JSON-бэкапа.

## 🚀 Установка и запуск

1. Установите расширение **Tampermonkey** в ваш браузер.
2. Откройте панель управления Tampermonkey -> вкладка **«Утилиты»** или нажмите значок `+` («Создать новый скрипт»).
3. Скопируйте и вставьте содержимое файла [`steam_licenses_manager.user.js`](./steam_licenses_manager.user.js).
4. Нажмите `Ctrl + S` (или «Файл» -> «Сохранить»).
5. Перейдите на страницу лицензий Steam: [https://store.steampowered.com/account/licenses/](https://store.steampowered.com/account/licenses/).
6. В правом нижнем углу появится плавающий виджет `[🎮 Лицензии DB: ...]`.

## 🖥 Режимы сбора лицензий

Во вкладке **⚡ Сбор данных** доступны действия:

1. **▶ Синхронизировать базу (Smart Sync)** *(Основная операция)*:
   - **Если база уже заполнена:** проверяет страницу 1 (самые свежие лицензии). Как только находит первую игру, которая уже есть в базе — моментально останавливается (< 0.1 сек.).
   - **Если появились новые покупки:** сохраняет только их и мгновенно завершает работу без сканирования старых страниц.
   - **Если база пуста:** последовательно обходит весь каталог от 1 до последней страницы (1–703).
2. **🔄 Возобновить (Resume)**:
   - Продолжает сбор с последней сохраненной страницы (если процесс был прерван или нажат «Пауза»).
   - Если вся библиотека уже выгружена — кнопка автоматически блокируется, защищая от случайных холостых запросов.
3. **⏸ Пауза** и **⏹ Стоп**:
   - Позволяют безопасно остановить процесс в любой момент с фиксацией контрольной точки.
