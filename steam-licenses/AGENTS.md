# AGENTS.md — Operational Manual: userscript-steam-licenses

## 1. Миссия, KPI и границы проекта (Mission & Scope)

- **Миссия:** Автономный Tampermonkey-юзерскрипт (`steam_licenses_manager.user.js`) для официального раздела лицензий аккаунта Steam (`https://store.steampowered.com/account/licenses*`), реализующий обход курсорной пагинации (`continuationToken`), полную выгрузку 70 000+ лицензий в локальную IndexedDB, интеллектуальную инкрементальную синхронизацию (Smart Sync) без холостых проходов и нативную форму быстрого перехода по страницам в стиле интерфейса Steam.
- **Ключевые KPI:**
  - 100% точность каталогизации лицензий 1-в-1 с Steam, включая дубликаты транзакций (`:::dup1`, `:::dup2`) и безымянные удаленные подписки.
  - Мгновенная остановка Smart Sync (< 0.1 сек.) при обнаружении первой ранее сохраненной лицензии на стр. 1.
  - Zero-Freezing: плавный поиск по 70 000+ записям с задержкой фильтрации < 50 мс.
  - Бесшовная интеграция с нативной пагинацией `.license_paginator_ctn`.
- **Границы и ограничения (Scope / Non-Goals):**
  - **In-Scope:** Индексация лицензий, IndexedDB (`LicensesDB`), пагинация по сохраненным курсорам `STORE_PAGES`, экспорт в JSON и CSV (UTF-8 BOM), поиск и прямой переход к строке.
  - **Non-Goals:** Активация ключей, удаление лицензий из аккаунта (скрипт строго read-only для инвентаризации).

## 3. Архитектурные правила и инварианты

1. **Единый самодостаточный юзерскрипт (`steam_licenses_manager.user.js`):**
   Не использует внешних `@require` или сторонних скриптов. Доступ к DOM осуществляется в контексте `document-idle`.
2. **Слой хранения IndexedDB (`LicensesDB`):**
   - База данных: `SteamLicensesDB` (v1).
   - Хранилище `licenses`: ключ `uniqueKey` вида `${title}|${packageId}|${date}|${type}(:::dupX)`.
   - Хранилище `pages`: сопоставление номера страницы `pageNum` и `continuationToken`.
   - Хранилище `meta`: состояние сбора, общее число страниц и прогресс.
3. **Smart Sync (Инкрементальное обновление):**
   При старте синхронизации анализируется страница 1. Если первая же прочитанная лицензия уже есть в базе — процесс немедленно завершается со статусом актуальности. Если обнаружены новинки — страницы опрашиваются последовательно вглубь до первой знакомой записи.
4. **Нативная пагинация в стиле Steam:**
   Форма пагинатора встраивается прямо в существующие контейнеры `.license_paginator_ctn` над и под таблицей лицензий, используя фирменные шрифты Motiva Sans и цветовую палитру Steam.

## 4. Подводные камни и нетривиальные решения

1. **Курсорная навигация Steam (`continuationToken`):**
   В Steam отсутствует параметр `page=N`. Для перехода на страницу N требуется точный `continuationToken` со страницы N-1. Скрипт кэширует цепочку токенов в IndexedDB, делая возможным произвольный прыжок на любую страницу.
2. **Дубликаты покупок и ключей:**
   Один и тот же товар может быть куплен несколько раз в одну секунду (кейсы, бандлы). Скрипт использует локальный счетчик повторений для формирования детерминированных уникальных ключей.
3. **Безопасность сессии пользователя:**
   Все запросы страниц выполняются в рамках текущей сессии через стандартный `fetch` без передачи cookies сторонним сервисам.
