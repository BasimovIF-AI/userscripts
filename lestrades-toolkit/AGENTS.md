# AGENTS.md — Operational Manual: userscript-lestrades-toolkit

## 1. Миссия, KPI и границы проекта (Mission & Scope)

- **Миссия:** Исчерпывающий технический справочник, контракт API и инструментарий для разработки расширений и юзерскриптов Tampermonkey для платформы обмена играми Lestrade's (`https://lestrades.com/*`). Содержит точные сигнатуры внутренних методов движка Wedge, контракты эндпоинтов автодополнения (игры, пользователи, разделы форума) и шаблоны инъекций в DOM.
- **Ключевые KPI:**
  - 100% точность спецификации эндпоинтов `/xml/game.php`, `/xml/users.php`, `/xml/boards.php`.
  - Стабильная работа хуков клиентского движка (`lt_change`, `show_ajax`, `hide_ajax`).
  - Готовые надежные шаблоны Tampermonkey без утечек памяти и конфликтов верстки.
- **Границы и ограничения (Scope / Non-Goals):**
  - **In-Scope:** Документация API, структуры данных предложений обмена, селекторы `.gametable`, скрипты автоматизации и шаблоны расширений.
  - **Non-Goals:** Спам-боты, взлом аккаунтов, несанкционированные транзакции.

## 3. Архитектурные правила и инварианты

1. **Структура движка сайта Lestrade's (Wedge Engine):**
   - Клиентский фреймворк: кастомизированный движок Wedge CMS на базе jQuery.
   - Сортировка списков игр: функция `lt_change(val)` выполняет локальную перестановку DOM `.gametable tbody > tr` либо AJAX-подгрузку `#glist`.
2. **Контракты ключевых API эндпоинтов:**
   - `/xml/game.php?q=<term>` — автодополнение игр (JSON-массив `{ id, v, f, s, i }`).
   - `/xml/users.php?q=<term>` — автодополнение пользователей (XML-структура `<item id="..." n="..." a="...">name</item>`).
   - `/xml/boards.php?q=<term>` — дерево разделов форума.
3. **Хуки сетевой активности:**
   Глобальный индикатор AJAX отображается/скрывается методами `show_ajax()` / `hide_ajax()`.

## 4. Подводные камни и нетривиальные решения

1. **Смешанный формат ответов (JSON vs XML):**
   Исторически эндпоинты Lestrade's возвращают разные форматы: `game.php` возвращает JSON, тогда как `users.php` возвращает чистый XML. Скрипты обязаны использовать соответствующий парсер (`JSON.parse` или `DOMParser`).
2. **Пагинация через AJAX-контейнер (`#glist`):**
   При динамической смене сортировки страницы `$('#glist').load(...)` перезаписывает внутренности таблицы. Любые пользовательские элементы должны регистрироваться через `MutationObserver` на контейнере `#glist`.
